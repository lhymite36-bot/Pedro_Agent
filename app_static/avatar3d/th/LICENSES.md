# Third-party avatar parts

- TalkingHead modules (`modules/`), MIT, (c) Mika Suominen — https://github.com/met4citizen/TalkingHead
- three.js + addons, MIT, (c) three.js authors — https://threejs.org
- `models/mpfb.glb` — TalkingHead sample avatar made with MPFB/MakeHuman assets (CC0).
- `models/male.glb` — built for Ped Bot from MakeHuman system assets (CC0) with the TalkingHead MPFB rig,
  weights and face targets (CC0). Shirt and eye textures recoloured. See tools/avatar_build.
- `anims/walking.fbx` — TalkingHead sample animation.
